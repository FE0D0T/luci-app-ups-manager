# UPS Manager: русский интерфейс и все наработки для OpenWrt

Эта папка содержит всё, чтобы на **чистом** пакете `luci-app-ups-manager` (китайском) восстановить перевод, исправления и новые функции.

## Что входит

| Папка / файл | Что внутри |
|---|---|
| `htdocs/` | переведённые страницы интерфейса (10 видов + вкладка «Звук») |
| `root/` | русское меню |
| `router/` | все файлы, которые ставятся на роутер (14 штук, плоским списком) |
| `installers/` | установщики: `install-windows.bat` (Windows) и `install-mac.sh` (macOS, Linux) |
| `STEPS.md` | пошаговая установка, если установщики не подходят |

## Что понадобится

1. **Роутер** с OpenWrt 25.x (проверено на 25.12.5, NanoPi R3S).
2. **Чистый пакет** `luci-app-ups-manager` установлен на роутере (проект `install.sh`).
3. **Компьютер** с OpenSSH:
   - Windows 10/11: «Параметры → Приложения → Дополнительные компоненты → OpenSSH Client» (включить один раз).
   - macOS и Linux: уже есть.
4. **Пароль пользователя `root`** роутера.
5. **IP роутера** (обычно `192.168.1.1`).
6. **USB-UPS** подключён к роутеру (проверено для Greencell UPSLP480, ID 0665:5161).

Ничего дополнительно ставить не нужно.

## Быстрая установка

**Windows:** дважды щёлкните `installers/install-windows.bat`, введите IP и пароль root.

**macOS / Linux:** в Terminal:
```sh
cd "путь/к/translate/installers"
bash install-mac.sh
```

Скрипт сам спросит IP и пароль, скопирует файлы и установит всё. Подробные шаги и ручной вариант — в `STEPS.md`.

## После установки

1. Откройте LuCI в режиме инкогнито (обычное обновление страницы может не сработать).
2. Проверьте вкладки: «Обзор», «История» (кнопка «24 часа»), «Энергия», «Звук», «Качество сети».
3. Если меню осталось китайским: на роутере `rm -rf /tmp/luci-indexcache /tmp/luci-modulecache/`.

## Откат

Чтобы вернуть китайский интерфейс, на роутере выполните:
```sh
sh /tmp/ups-restore/router-restore.sh
sh /tmp/ups-restore/router-journal-restore.sh
sh /tmp/ups-restore/router-beeper-restore.sh
```

## Важно

- Данные истории и энергии хранятся в `/tmp` роутера и пропадают при перезагрузке.
- При переустановке или обновлении пакета UPS Manager установку нужно повторить.
- Перевод машинный, без проверки носителем языка.
